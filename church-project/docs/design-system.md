# Design Philosophy

The design should create a feeling of

- Professional
- Modern
- Clean
- Elegant
- Welcoming
- Peaceful
- Christian
- Easy to Navigate
- Mobile First

The UI should have plenty of white space, clear typography, and consistent spacing.

# UI Rules

- Every section uses the same container width.
- Every page starts below the Navbar.
- Every section has consistent vertical spacing.
- Every card uses the same border radius.
- Every button follows the same design.
- Images should keep consistent aspect ratios.
- Typography must remain consistent across all pages.
- Use reusable React components whenever possible.
- Mobile-first responsive development.
- Accessibility should be considered for buttons, forms, and navigation.
