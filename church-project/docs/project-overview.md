# Church Platform

## Project Description

Church Platform is a modern, responsive church website inspired by the GEEC Vancouver website. The project aims to provide church members and visitors with an easy and engaging digital experience while following modern software engineering practices.

The application will be built using Next.js, React, Tailwind CSS, and JavaScript.

This project will become a portfolio-quality application that demonstrates professional frontend architecture, reusable components, responsive design, and future AI integration.

---

## Project Vision

Build a modern church platform that is clean, scalable, maintainable, and easy to expand in the future.

---

## Project Objectives

- Build a modern responsive website
- Improve user experience
- Follow professional folder architecture
- Use reusable React components
- Prepare the project for AI integration
- Build a portfolio-quality application
